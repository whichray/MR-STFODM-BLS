# Attribution and distribution status

This local code candidate retains the original source comments and module descriptions. No new license grant is made by its preparation.

`core/fractional_attention_entropy.py` identifies itself as a Python implementation of supplied MATLAB routines, including `FracAttenEn.m` and `HFrAttEn.m`. The source collection inspected for this release did not contain an explicit license file for these routines. Their redistribution terms remain unverified. Before publishing the package, the authors should establish the relevant rights/terms, retain required notices and select a suitable license for their own code. A bibliographic citation alone does not establish code redistribution permission.

The manuscript attributes the hierarchical fractional-order attention entropy method to the following reference, reproduced here from the author-supplied manuscript, without a new bibliographic verification in this packaging task:

Yang J, Li X, Mao M. Research on Improved Transformer Fault Diagnosis Method Driven by IBKA-VMD and Hierarchical Fractional Order Attention Entropy Synergy. *Fractal and Fractional*. 2026;10(3):195. DOI: 10.3390/fractalfract10030195.

NumPy, SciPy, scikit-learn, pandas, threadpoolctl and WFDB are installed separately and retain their own licenses; their source distributions are not bundled here. MIT-BIH data are also obtained separately and remain subject to their own database terms and citation requirements.

The original MATLAB files, comparison-method source code and database files are not included in this package. Absence of a selected code license is deliberate pending an author decision; do not describe this candidate as MIT-licensed or otherwise grant broad reuse rights on the authors' behalf.
